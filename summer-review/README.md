# 🏖️ 四年级暑假快乐复习营

给四年级小朋友做的暑假复习网站：**一个总站，英语 / 数学 / 科学各一个标签页**，用动画、互动演示和小游戏把知识复习得又牢又开心。

## 怎么打开

纯静态网页，**不用安装任何东西**：直接双击 `index.html` 用浏览器打开即可（Chrome / Edge / Safari 都可以）。

> 英语发音用的是浏览器自带的语音合成（TTS），第一次点 🔊 如果没声音，稍等一两秒再点一次。

## 有什么内容

### 🔤 英语乐园
- **单词闪卡**：天气 / 衣服 / 农场动物 / 食物 / 学校 5 大主题 40 个单词，点卡片翻面看中文，点 🔊 听发音
- **句型跟读**：8 个四年级核心句型，可听发音、看中文
- **单词配对**：英语单词 ↔ 图片连连看
- **听音选图**：听发音选出正确图片，实时计分

### 🔢 数学王国
- **角的度量**：拖滑块转动射线，量角器实时读数并判断锐角/直角/钝角/平角
- **三角形内角和动画**：三个角"撕"下来拼成平角，直观看到 180°
- **小数的意义**：百格图涂色，小数 / 分数 / 读法联动变化
- **运算定律卡片** + 巧算妙招（25×4、125×8）
- **口算大挑战**：乘除、小数加减混合出题，连对越多火苗越旺 🔥

### 🔬 科学实验室
- **水循环动画**：蒸发 → 凝结 → 降水 → 汇流，可播放/暂停
- **点亮小灯泡**：点开关闭合电路，电流流动、灯泡发光
- **月相变化**：拖滑块看新月到残月的完整变化
- **声音的产生**：敲音叉看振动、听声音（WebAudio 真的会响）
- **科学知识卡片**：植物、动物繁殖、声音、天气、土壤、安全用电

### 🚩 闯关测验 & 星星
每科 10 道闯关题，答对 90% 拿 ⭐⭐⭐；星星记录保存在浏览器本地，首页随时能看到三科进度。

## 文件结构

```
index.html   页面骨架（四个标签页）
styles.css   全部样式和动画
app.js       标签切换、星星进度、发音、测验引擎
english.js   英语内容与游戏
math.js      数学演示与口算
science.js   科学动画与实验
```
