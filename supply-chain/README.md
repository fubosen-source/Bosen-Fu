# BOSEN 供应链管理系统

> 本目录有两个版本：`index.html` 是 V1（仿 ZONET 界面的红色主题版）；`v2/index.html` 是 **V2 供应链控制台**（推荐）——在 V1 全部功能之上，结合业务重新设计：新增**到港清关**独立阶段、**今日关注**异常面板（逾期 / 阶段滞留 / 缺ETA / 7天内到达）、**国家概览卡**（本地库存 / 在途+清关 / 生产端 / 最近到货）、**货值 USD** 统计、时间线**每阶段停留天数**、国家页签切换、深色模式。两版数据相互独立，均存 localStorage。

总部、采购、运营、各国家仓库共用的货物进度台账。纯前端单文件应用，**无需安装任何依赖，双击 `index.html` 用浏览器打开即可使用**，数据保存在当前浏览器的 localStorage。

## 功能

- **登录 / 注销**：姓名 + 角色（总部 / 采购 / 运营 / 国家仓库），只做本机身份标记
- **六阶段货物进程**：已下单待生产 → 已下单生产中 → 生产完成 → 空运在途（4A）/ 海运在途（4B）→ 目的国库存
- **概览统计卡**：各阶段数量与批次数，按当前国家筛选联动，点击卡片即筛选
- **货物进程图**：从下单到目的国库存的流程视图，空运 / 海运并行分支，点击阶段即筛选
- **批次明细表**：状态徽章、国家、订单/批次、运输方式、设备、数量、当前位置、预计到达（自动计算剩余天数 / **已逾期X天** 红色提示，入库批次显示"已入库"）；数量、预计到达列可点击表头排序（升序 → 降序 → 恢复默认）
- **逾期提醒**：概览区自动显示"⚠ N 个批次已逾期"，点击直接筛选出逾期批次
- **搜索与筛选**：关键词搜索（国家、订单号、供应商、设备、型号、柜号、备注），状态、国家下拉；「更多筛选」含运输方式、供应商、是否逾期
- **详情侧栏**：点击表格行查看完整字段与**状态历史时间线**，一键**推进到下一状态**（生产完成后按运输方式自动进入空运或海运分支），每次流转自动记录时间
- **新增 / 编辑 / 删除批次**：订单号、批次名称、状态、国家、设备、类型、数量、供应商、柜号/运单号、位置、下单日期、预计到达、备注
- **导出 CSV**：按当前筛选导出，带 BOM，Excel 直接打开不乱码
- **恢复示例**：一键还原示例数据

## 数据说明

所有数据仅保存在当前浏览器（localStorage），不上传任何服务器。换浏览器或清除站点数据会丢失记录，重要数据请定期「导出 CSV」备份。

## 技术

单文件 HTML + 原生 CSS / JavaScript，零依赖、完全离线。
